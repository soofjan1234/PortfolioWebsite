## 实际改动

- 从第一版 Blender 源生成候选，解除皮肤、衣服与镜框的共用材质；皮肤使用暖色区域、粗糙度贴图与降低强度的原法线，牙齿、眉毛、嘴唇及口腔有独立保护判断。鼻尖和耳朵的暖红底色按部位区分，避免被误当成嘴唇排除。
- 基于真实眼窝边界增加窄眼睑过渡带，原完整眼球增加球面 UV 和放射状虹膜纹理，保留眼球几何与球心；默认朝向按用户后续反馈调整。纯色眼睑避免拉伸原纹理里的锯齿黑边。
- 在固定发际线边界的前提下整理头顶局部形体、清除减面后残留的旧分裂法线，重建头发 UV 并烘焙蓝黑底色与粗糙度层次。
- 浏览器采用灰绿背景、暖色大面积光源、低强度投影光及冷色补光。默认入口加载已验收正式模型，`?quality=candidate` 查看精修副本，`lighting=baseline` 对照原布光。宽屏控制面板缩窄，减少对脸部特写的遮挡。

可恢复第一版为 [baseline.glb](baseline.glb)，其 SHA-256 与原交付一致。候选自包含材质、贴图、相机与动画，详见 [最终报告](final-report.json)。

## 目光与眉眼修复

用户接受整体质感后，追加增大目光范围、拉开眼珠间距，并指出眉毛附近及右眼外侧仍有破碎边缘。当前修改限定于候选模型与验收页，保持球心、眼眶总体位置、履历相机动画、身份与表情。

- **目光与间距**：保留此前水平 ±0.38 rad、垂直 ±0.22 rad 的跟随范围；两侧默认朝向各外偏 0.12 rad（约 7°）。模型正面 X 方向的瞳孔中心间距由 0.209018 增至 0.235454，增加约 12.6%；该数值不代表任意相机下的像素距离。
- **眼睑折返**：原共享切口存在锯齿回折，分别产生 38、41 个背向三角面。整理共享边界、向邻接皮肤缓释位移，再按同一轮廓中心生成同序内圈后，两侧背向面均为 0。外表面最小球面间隙分别为 0.002787、0.002922。
- **眼角透视缝隙**：只有间隙检查不足以证明封闭。放大相机下的右眼外侧视线原来穿过薄眼睑，命中距离 1.50786 的后脑头发，形成黑线。新增向眼球内部延伸 0.003 的内封边后，同一视线先命中距离 0.975724 的眼睑。外表面避免穿插、内部接触面封口分别验证，不能把两类面混成“全部位于球面外”的标准。
- **眉毛与刘海**：原分类按高度误拆了眉上 75 个面、刘海发梢 93 个面，使用不同材质且接缝未焊合。眉毛接回头部并从原模型恢复 UV，发梢接回头发；双向补齐减面形成的 T 接点后焊接，移除旧面，两个区域均无剩余开边。
- **回归与构建**：眼睑背向检查、眼角射线检查均先复现失败再通过；10 项精修测试、10 项模型测试通过。候选 glTF 0 错误、0 警告，预览页独立构建通过，保留既有 Browserslist 和大包提示。本次未重复未改动的主页构建。
- **兼容性**：两个眼球中心和缩放不变，默认外偏旋转误差小于 0.000001 rad；履历相机与五个焦点变换不变，相机轨道数值最大差异为 0、时间轴一致。浏览器四角目光、关闭跟随、左右斜侧近景均已检查，当前控制台无警告或错误。

## 外眼角白块与眼周色差修复

用户的新放大图明确指出外眼角皮肤上的白色楔形。前一轮处理的是眼睑内侧黑缝，未覆盖此处。射线确认白块命中头部网格，底色贴图 UV `(0.742585, 0.589431)` 的颜色接近白色；原始贴图同处也为旧眼白。原清理遮罩要求深度接近正面 `Y=-0.27`，漏掉实际位于 `Y=-0.216` 的侧眼角。

- **白块**：增加随各眼球中心定位的局部区域，在烘焙时按原贴图逐像素识别亮白残留。该逻辑只作用于头部的眼周，不改变独立眼球、牙齿或嘴部。相同采样点 sRGB 由 `(0.969, 0.937, 0.898)` 变为 `(0.875, 0.561, 0.435)`，相邻健康皮肤的回归采样保持在原值容差内。
- **灰青眼周**：旧修补底色线性 RGB 为 `(0.49, 0.265, 0.16)`，红分量低于相邻暖皮肤。中性补光单变量对照仅减轻冷色，不能消除这圈底色色差。将眼周与眼睑统一匹配相邻皮肤为 `(0.74, 0.275, 0.16)`；预览布光保持原值。
- **当前验证**：两项定点回归先失败再通过；生成候选后运行全部 12 项 Python 测试和 10 项 Node 测试，全部通过。候选官方校验 0 错误、0 警告；浏览器正面、斜侧与右上转动目光均未复现该白块，控制台无新增警告或错误。本轮未修改预览页代码，未重复旧构建。
- **兼容性**：头部、眼睑、眼球、镜框与衣服 7 个网格顶点位置完全一致；头发重新生成的最大数值偏差为 `0.000002116`。目光范围、默认外偏、球心、相机和动画契约保持通过，见 [兼容性记录](compatibility.json)。

复现时先运行 `.codex-model-tools/bin/python scripts/refine-character-quality.py --stage=final`，再运行 `.codex-model-tools/bin/python -m unittest scripts/test_refine_character_quality.py`；新增两项测试直接检查烘焙候选，避免只验证遮罩函数而漏掉实际贴图。

## 脖子黑三角与侧发白片修复

用户从两侧观察发现脖子上的黑色三角块，以及左侧头发中的白色细片。本轮分别通过射线、原始贴图与连通分量定位原因。

- **脖子黑块**：原始贴图此处为正常皮肤，当前头部 UV `(0.059898, 0.884366)` 却被脖子与眉部两个三角面共同覆盖。原因是先前恢复眉部 UV 时逐顶点寻找最近原面，跨贴图岛产生长三角，烘焙眉色覆盖脖子。现按目标面中心固定原始三角面及 UV 分区，同一面的所有面角在该连续映射下投影；回归检查确认此处仅剩脖子一处映射。实际 sRGB 由 `(0.224, 0.169, 0.149)` 恢复为 `(0.925, 0.588, 0.439)`。
- **头发白片**：白片属于误归头部的独立 106 面表面，原始纹理此处为亮色。将其转入头发，补齐 6 个边接点并焊合；另封闭一个长约 0.0032、宽约 0.00055 的三角缝隙。封缝仅限本次局部接合区内、短且窄的三角闭环；最终剩余开边为 0。同一视线现在命中头发，底色由接近白色变为蓝黑色。
- **验证**：新增 3 项回归先复现失败再通过；全部 15 项 Python 测试与 10 项 Node 测试通过。官方模型校验 0 错误、0 警告；眼球默认朝向、球心、相机与动画契约通过。浏览器检查左右侧、背面及眉眼特写，标记的两处异常未复现，渲染日志无新增警告或错误。预览代码未修改，未重复构建。
