# 人物质感联合精修设计

当前以已验收的精修编辑源继续改善眼睛、材质和灯光，制作独立自然质感候选。2026-10-08 用户选择先做这三项；嘴角和牙齿不在本轮范围。确认与实施进度统一记录在 [主题状态](../status.md)。

## 当前：自然质感候选（2026-10-08 已确认）

目标：保留身份、眼镜、发型和五官比例，使眼睛连接更自然、不同部位的光泽更清楚，增强脸部体积。

方案：从已验收 `quality-refinement/hou-quality-candidate.blend` 生成独立候选。固定眼睑外圈与头部交界，仅整理内侧开口、增加圆顺过渡；保持眼球网格、球心及默认朝向。眼球降低粗糙度并增加薄清漆反光；皮肤仅在既有皮肤遮罩内调整表面响应，保护嘴唇、牙齿、眉毛及衣服；头发增加柔和反光，镜框保留更清晰的高光。网页采用更明确的暖中性主光、低强度环境和补光，保留手机性能策略。

最小契约：输入为已验收编辑源；输出独立 `public/models/me-natural-candidate.glb`、可编辑候选源及检查报告。正式 me.glb 不自动覆盖。网页仅通过白名单参数 `quality=natural` 加载候选，`lighting=baseline` 可在原灯光下隔离材质变化；普通入口沿用正式模型和当前灯光。相机、焦点、眼球变换及非眼睑网格顶点保持不变，嘴部底色保持不变；沿用主页滚动、近景和工具栏稳定性契约。

验证：先锁定眼睑外圈、球面间隙、封边及区域保护的失败回归；再检查真实候选网格、贴图、材质扩展和模型结构/交互契约。固定网页镜头对照正式版、同布光候选和新布光候选，检查正面、特写、斜侧与目光转动。最终运行相关全量与构建；外观通过用户视觉验收后再替换正式版。

当前候选实现和验证证据见 [自然质感验收记录](../assets/model/natural-refinement/verification.md)，正式替换仍待视觉确认。

以下内容为首次质感精修的历史设计，保留其来源与交互约束；当前实现以本节契约为准。

## 目标与范围

精修范围为皮肤、眼睛、头发及预览布光。人物身份、黑框眼镜、浅色上衣与现有表情沿用已确认造型。第二张图用于质感对照，贴纸、发型和夸张表情的复刻不属于本轮范围。

本轮在模型验收页验证外观，视觉通过后再按 [总体设计](../design.md) 接入正式主页。

## 当前事实与方案选择

第一版预览已有环境光、阴影和可关闭的景深。当前皮肤、衣服与镜框共用生成材质，眼白、虹膜和瞳孔为纯色材质；头发主要经过内部平滑、统一黑色材质和减面。既有皮肤参数离线对照改善有限，详见 [质感对照结果](../status.md#质感对照结果)。

| 方案 | 收益 | 限制与代价 |
| --- | --- | --- |
| 仅调整材质和灯光 | 改动较小，较快检验颜色与高光方向 | 无法解决发束体积和眼睑交界；既有对照改善有限 |
| 材质、局部形体和灯光联合精修（采用） | 同时改善肤色、高光、发束和眼部接合 | 需要真实模型编辑与多视角验收，工作量较大 |

## 改动方案

| 部位 | 实现方向 | 可见结果 |
| --- | --- | --- |
| 皮肤 | 拆出独立材质；在保留 UV 的基础上调整底色和粗糙度，增加鼻尖、脸颊及耳朵的暖红变化，控制法线细节强度 | 肤色有局部变化，高光宽柔，近景有细节且不显油亮 |
| 眼睛 | 改善眼睑与眼球交界，补充虹膜纹理层次，调整眼白亮度及反光 | 眼球融入眼窝，目光清晰，转动后边缘完整 |
| 头发 | 整理厚实连续的发束体积，保留少量方向凹槽，以宽柔冷色高光表现层次 | 黑发具有连续体积，侧面和背面无尖碎突起、穿插或空洞 |
| 灯光与背景 | 调整暖色主光、冷色轮廓光和环境补光，控制阴影过渡；采用低饱和灰绿背景 | 脸部有暖色体积，头发及边缘有冷色层次，暗部仍可辨认 |

模型材质负责底色、纹理及表面响应；网页预览负责灯光、背景、曝光与景深。最终质感以网页实际加载的 GLB 为准。离线渲染用于辅助检查，不替代浏览器验收。

皮肤参数及灯光强度通过固定镜头对照确定，不预先承诺未经验证的数值。若拟采用的材质效果不能完整导出或在浏览器中一致呈现，优先使用可验证的贴图与表面参数；新增自定义着色方案须补充设计依据。

## 最小输入与输出契约

| 项目 | 要求 |
| --- | --- |
| 输入 | 第一版 GLB 与可编辑源、保留的原始彩色模型、已确认人物正面 v5、用户本轮两张质感对照图 |
| 可编辑输出 | 可继续调整几何、材质和动画的 Blender 场景，保留原始输入与第一版基线 |
| 网页输出 | 自包含的 `public/models/me.glb`，纹理可解析，材质在真实预览中生效 |
| 交互兼容 | 遵守 [总体设计的最小模型契约](../design.md#最小模型契约)，眼球旋转中心、相机动画和焦点保持有效 |
| 验收证据 | 固定镜头的前后截图，包含正面、侧面、背面及面部特写；记录景深状态、关键设置、模型校验摘要与 SHA-256 |

候选结果通过外观与结构检查后再替换交付模型。检查失败时保留基线并记录首个差异；原始模型作为恢复与继续编辑的依据。

## 验证标准

1. 固定相机、分辨率、目光和景深状态，比较第一版与候选结果；材质与形体对照保持相同布光，最终整体对照明确记录灯光变化。
2. 正面及特写可辨认脸颊、鼻尖、耳朵的暖色变化；高光柔和，关闭景深后眼部与皮肤细节仍成立。
3. 侧面、背面及头部旋转过程中，发际线与头部接合完整，眼睑无明显破面，眼镜与眼球无新增穿插。
4. 真实浏览器中验证 GLB 加载、目光跟随、正面/侧面/背面/特写切换，以及相机动画首尾与反向返回；触屏分支继续可用。
5. 按“RED → 目标 GREEN → 最终相关全量”验证新增或受影响的可自动检查行为；最终执行模型就绪检查、相关测试与生产构建。美术标准通过固定镜头截图及人工验收判定，不以结构检查通过替代视觉结论。
6. 大型制品只报告数量、关键字段、首个差异与哈希，完整证据保存到主题资产目录。

达到上述标准后，提交真实浏览器对照供外观验收；文档落盘与设计确认均不代表精修已经完成。
